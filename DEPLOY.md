# Раскатка общей админки

Адрес: https://admin.cloudguardadvisory.com. https://admin.zenthracore.com перенаправляет туда. EU/UA отдельные админки не запускают.

## До обновления

- Сделать резервную копию БД и приватного storage. Проверить фактический способ хранения PDF: обновление контейнера без volume удаляет его локальные файлы.
- В окружении .com задать ADMIN_TOKEN: случайный секрет 32–256 символов. Старый default больше не принимается. Генерация на сервере: `openssl rand -hex 32`; сохранить в защищённом env, не в Git.
- POSTGRES_PASSWORD должен совпадать с паролем существующей роли БД. Изменение переменной не меняет пароль в существующем PostgreSQL volume.
- Gateway теперь требует Basic Auth для всех посетителей админки. Проверить zen.gateway/.htpasswd и знать свою учётную запись до применения конфигурации.
- Cloudflare Access/MFA/Turnstile в этой версии ЕЩЁ НЕ ПОДКЛЮЧЕНЫ. Их идентификаторы и ключи не нужны для просмотра текущей версии.

## Обновление

Из корня репозитория:

```sh
git pull --ff-only
cd zenthracore.com
docker compose config --quiet
docker compose up -d --build backend admin
```

Обновлять backend и admin вместе: старый X-Admin-Token больше не открывает защищённые API, вход создаёт HttpOnly-cookie. Backend работает под непривилегированным пользователем: существующий storage должен быть доступен этому пользователю.

Если меняются остальные compose-сервисы, пересоздать их в согласованное окно: привязка портов к localhost применяется только при пересоздании. Не удалять database volume.

Для gateway из корня:

```sh
cd zen.gateway
docker compose exec gateway nginx -t
docker compose exec gateway nginx -s reload
```

Reload выполнять только после успешного nginx -t. Nginx в рабочем окружении аудитора не был доступен для этой проверки.

## Проверка

Открыть HTTPS-адрес админки, пройти Basic Auth и войти новым ADMIN_TOKEN. Проверить загрузку заявок/статей, мобильный экран, выход и повторный вход. Письмо, публикацию или Jira-синхронизацию не нажимать ради визуального теста на реальных клиентах.

После обновления: 15 минут бездействия / час максимум на сессию; ссылки на брифы старше 30 дней перестают открываться; публичный просмотр счёта по номеру закрыт до реализации защищённых клиентских ссылок. Подробности и оставшиеся release gates: ../../SECURITY-HARDENING.md.
